# Sveltia CMS Authenticator

A [Cloudflare Worker](https://workers.cloudflare.com/) for signing in to [Sveltia CMS](https://sveltiacms.app/en/) with GitHub. Powered by [`@lightnet/sveltia-github-auth`](https://www.npmjs.com/package/@lightnet/sveltia-github-auth).

Follow the [LightNet setup guide](https://docs.lightnet.community/content/setup-github-auth/) to deploy the Worker, configure GitHub OAuth, and connect your CMS.
